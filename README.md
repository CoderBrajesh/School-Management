# 🎓 School Management System

A modern and responsive **School Management System** built using HTML, CSS, and JavaScript.

This project provides an admin dashboard for managing important school activities such as students, teachers, attendance, classes, examinations, results, fees, and notices.

## 🚀 Features

### 📊 Dashboard
- School overview
- Statistics and summary cards
- Quick access to management modules
- Admin profile section

### 👨‍🎓 Student Management
- Add students
- Edit student information
- Delete students
- Search and manage student records
- Student data management

###  Teacher Management
- Add teachers
- Edit teacher information
- Delete teachers
- Subject management
- Teacher records

###  Attendance Management
- Manage student attendance
- Attendance records
- Attendance statistics
- Present/Absent tracking

###  Class Management
- Manage school classes
- Class information
- Student/class organization

###  Examination Management
- Manage examinations
- Exam information
- Examination records

###  Results Management
- Manage student results
- Passed and failed students
- Average percentage
- Result records

###  Fee Management
- Manage student fees
- Fee records
- Payment status
- Fee statistics

###  Notice Board
- Create school notices
- Manage announcements
- Active notices
- Notice records

### Responsive Design
- Desktop friendly
- Tablet friendly
- Mobile responsive
- Responsive sidebar and dashboard

##  Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
- Responsive Web Design
- Local Storage
